# 阶段二：个人项目总首页

账号与仓库：Herz1/project-archive，公开。

## 当前完成

- 可复用 Skill、1,506 份原样源文件及逐文件校验；
- 两套参考体验的工作副本生成器；
- 原始体验保留地图、素材许可说明、首轮研究与截图；
- 独立 Skill 和完整整合包的打包入口。

## 最新设计约束

用户希望最大化保留原来的精髓，可以大量原样保留代码，不要从头做。先选择随包原始程序为起点，再用小而可审阅的适配连接个人项目数据。

这一约束覆盖首轮研究中建议默认重写、缩短开篇或减少原始体验的部分。是否缩短开场、合并章节、改明暗或削减三维，应由第二步的明确需求或实际验证问题决定。

## 实现

用户确认开始第二步后，在 `website/` 中以原始源码展开：Eidolon 作为八幕光谱入口，Rhine 作为三维项目档案，另接标准 HTML 轻量目录。构建边界独立，最终部署在同一仓库的 GitHub Pages `/project-archive/`。

公开范围核对为 Herz1 本人拥有的全部公开仓库，未发现需追加的组织；当前 14 个，包含 1 个 Fork 与 2 个真正的空仓库。保留稳定 GitHub 数字 ID、档案编号、真实源码与已核对的演示地址。大小为 0 KiB 的 README 仓库没有误标为空。

完整开场、分光、光谱、手机、浮岛、玻璃、抽取与解密继续使用原实现；品牌、叙事和档案内容连接个人项目。标准链接、项目完整性和无 WebGL 回退与视觉保留同等重要。

开发、更新与发布见 [website/README.md](../website/README.md)。实际修改和验证见 [实现记录](../website/docs/implementation.md)。原始层始终独立校验。没有设置定时任务；每次推送或手动运行发布工作流时同步公开项目数据。
